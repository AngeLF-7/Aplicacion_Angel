# 🚀 DeepCore — Deep Work & Discipline Tracker

**DeepCore** es una aplicación móvil nativa para **Android** desarrollada en **Kotlin** como Proyecto Intermodular de 2.º de Desarrollo de Aplicaciones Multiplataforma (DAM). 

Su objetivo es ayudar a estudiantes y desarrolladores a alcanzar estados de concentración profunda (*Deep Work* / *Flow*), organizar sus bloques de estudio en un calendario, validar el aprendizaje real mediante mini-cuestionarios generados por Inteligencia Artificial y medir su constancia diaria a través de un sistema de puntuación personal (**MMR**).

## 🛠️ Stack Tecnológico

* **Plataforma:** Android (API 24 / Android 7.0 Nougat o superior)
* **Lenguaje:** Kotlin
* **Arquitectura:** MVVM (*Model-View-ViewModel*) + patrón *Repository*
* **Backend & Autenticación:** Firebase Authentication & Cloud Firestore
* **Persistencia Local (*Offline-First*):** Room Database (SQLite)
* **Inteligencia Artificial:** Google Gemini API *(planificada para fases avanzadas)*
* **Control de Versiones:** Git & GitHub
